# 🪟 창문 공방 — 파이썬 tkinter 수업

> © 2026 티쳐무 · 모든 권리 보유 · 학교 수업 목적으로만 이용해 주세요 (자세한 내용은 `LICENSE`)

고등학교 「정보」 파이썬 수업의 **tkinter(GUI 프로그래밍)** 단원을 위한 웹앱입니다.
교재 「고등학교 정보 파이썬 프로그래밍 통합 교재」 13장 「tkinter로 창이 있는 프로그램 만들기」 를 따라갑니다.

## 왜 만들었나
tkinter 는 **구글 코랩에서 창이 뜨지 않습니다.** 그래서 이 앱은 브라우저 안에 「가짜 tkinter」 를 만들어,
학생이 쓴 tkinter 코드가 그 자리에서 진짜처럼 창을 띄우고, 단추를 누르면 연결한 함수가 불리게 했습니다.

- 위젯의 **자리와 크기**는 진짜 Tk(윈도 · 파이썬 3.12)와 같은 규칙으로 셈합니다.
  교재 13장의 tkinter 코드 39개를 포함한 프로그램 160개를 진짜 tkinter 와 자동으로 대조합니다
  (단추 누르기 · 글자 치기 · 마우스 끌기 · 키 누르기를 한 뒤의 모습까지).
- **오류 문구**도 진짜와 같습니다 — `_tkinter.TclError` · `Exception in Tkinter callback` 의 Traceback 까지.
  오류마다 한국어 풀이가 붙습니다.
- **조용한 실수**를 눈에 보이게 — `mainloop()` 를 빠뜨리면 창이 번쩍하고 사라지고,
  `pack()` 을 빠뜨린 위젯은 🔍 엑스레이의 「대기실」 에 앉아 있습니다.
- 인터넷 없이 `dist/index.html` 한 파일로 열립니다(글꼴만 인터넷에서 받고, 없으면 맑은 고딕).

## 1차시 · 카드 10장 — 창과 위젯 (교재 1~4절)
| # | 카드 | 하는 일 |
|---|---|---|
| 0 | 공방 문을 열며 | 같은 숫자 맞추기를 글자 프로그램 · 창 프로그램으로 — 창 프로그램엔 왜 `while True` 가 없을까? |
| 1 | 첫 창 띄우기 | `Tk()` · `title` · `geometry` · `mainloop()` — mainloop 를 지우면 번쩍! |
| 2 | 위젯 놓기 | 만들기 ≠ 놓기 — 엑스레이의 대기실 |
| 3 | 옵션 바꾸기 | 옵션 실험대(bg · fg · font · relief …) · `label.text = …` 의 함정 |
| 4 | pack | 블록 쌓기로 「남은 자리」 규칙 · 예측 문제 |
| 5 | grid | 칸 레고 · 교재 확인 문제 5 |
| 6 | place | 좌표 과녁 맞히기 (y 는 아래로 커진다) |
| 7 | 섞으면? | pack 과 grid 를 섞으면 TclError → Frame 으로 고치기 |
| 8 | 의뢰 1 | 「꿈누리 분식 주문서」 목표 화면 똑같이 만들기 — 별 셋 · 닮은 정도 % |
| 9 | 확인 문제 | 교재 확인 문제 1~5 꼴 + 오늘 배운 것 |

## 쓰는 법
1. `dist/index.html` 을 열거나(더블클릭) 배포된 주소로 들어갑니다. ← → 키로 카드를 넘깁니다.
2. 편집기에서 코드를 고치고 **▶ 실행**(Ctrl+Enter) — 오른쪽 바탕 화면에 창이 뜹니다. 창의 단추 · 입력 칸을 실제로 눌러 볼 수 있습니다.
3. **⬇ .py** 로 코드를 내려받아 IDLE 에서 F5 를 누르면 진짜 창으로 확인할 수 있습니다.
   3차시 마지막 카드에서 그동안 쓴 코드를 .zip 하나로 모아 받을 수 있습니다.

주소 끝에 `?demo` 를 붙이면 편집기마다 모범 답이 들어 있습니다(선생님 시연용).

## 개발
```bash
npm install
npm start          # 개발 서버 (http://localhost:5330)
npm test           # 시험 — 진짜 tkinter 대조 · 미션 검사 · 엔진
npm run build      # dist/index.html 한 파일 + 빌드 점검
npm run check:syntax
npm run golden     # 진짜 파이썬 · tkinter 로 대조 기준(test/golden.json)을 다시 만든다 (윈도 + 파이썬 3.12 필요)
npm run metrics    # 진짜 Tk 에서 글꼴 너비 · 위젯 크기 · 색 이름을 다시 잰다
```
